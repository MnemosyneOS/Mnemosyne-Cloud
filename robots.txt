# ============================================================================
# 三类 AI bot 分层
#
# 2026 年主流 AI 平台普遍把爬虫拆成三类，用途不同、策略不同：
#
#   搜索索引 bot —— 抓取内容用于「实时检索后回答」。封禁 = 内容不会出现在
#                   对应平台的回答里。对本站是核心可见性，必须 Allow。
#   用户检索 bot —— 由真实用户的查询触发（用户贴了一个链接，模型去读它）。
#                   多数不完全遵守 robots.txt，但显式放行无副作用。
#   训练 bot     —— 抓取内容用于训练未来模型。不影响当前可见性，
#                   只影响内容是否进入训练集。由站点所有者决定。
#
# 本站立场：MIT 代码 + 公开文档 + CC BY-NC-ND 手册，全部对检索与训练开放。
# 封禁的只有托管控制台（/api/ /auth/ /stats/ /admin/），那是用户私有数据。
# ============================================================================
