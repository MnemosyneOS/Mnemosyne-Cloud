Agent 记忆的生命周期：写入、巩固、检索、更新、遗忘

AI 记忆的生命周期由六个核心操作构成：写入（Ingestion）、索引（Indexing）、巩固（Consolidation）、检索（Retrieval）、更新（Updating）、遗忘（Forgetting）。完整链条可表示为 ENCODE → RETAIN → CONSOLIDATE → RETRIEVE → REVISE → FORGET → INHERIT，每个环节都有独立的失败模式，任一环缺失都会让整条链退化。

Agent 记忆怎么写进去？写入流程的五个步骤

记忆写入不是「把对话存下来」，而是一条五步流水线：先判断这条内容是否值得记（显著性判定），再抽取结构化事实（实体、谓词、时间），然后与已有记忆去重并消解冲突，接着写入并建索引，最后记一条审计记录。跳过任一步都会在生产环境付出代价。

  1. 1. 显著性判定区分「寒暄」与「事实」。不是所有对话都值得成为记忆，全存等于没存。
  2. 2. 结构化抽取把自然语言拆成实体、关系、时间、数值。这是后续检索精度的上限。
  3. 3. 去重与冲突消解同一事实重复出现应合并；新事实与旧事实矛盾时，按时间与来源决定取舍。
  4. 4. 写入与索引落盘并建立多路索引（语义、关键词、实体、时间）。
  5. 5. 审计记录记录「谁在何时写了什么、依据是什么」，供事后追溯。
Mnemosyne OS 采用单遍 ADD-only 抽取：每次写入只调用一次模型，记忆只累积、不覆盖。这个设计的取舍是——坏的抽取只会引入噪声，永远不会销毁一条真实记忆。对生产系统来说，误删比误存昂贵得多。

记忆巩固（Consolidation）是怎么把情景变成语义的

记忆巩固是把重复出现的情景记忆提炼为语义记忆的过程：多条「用户周三说喜欢深色模式」「用户周五又调成深色」被合并成一条「用户偏好深色模式」。它的工程价值在于压缩——用一条语义记忆替代 N 条情景记忆，同时提高检索命中率。

阶段 输入 输出 触发条件
情景累积单次事件带时间戳的情景记忆每次交互
模式识别多条相似情景候选语义同一谓词出现 ≥ N 次
语义沉淀候选语义去时间化的事实跨会话复现
衰减低访问语义降级或归档长期未命中
Mnemosyne OS 的巩固路径把重复出现的情景提炼为语义；配合分层记忆（hot / warm / cold），低价值记忆被降级并压缩而非静默删除。压缩后的记忆可通过 expand() 逐字节还原原文并校验哈希。

记忆检索（Retrieval）怎么调？四路信号与融合顺序

记忆检索的调参核心不是「top_k 调多大」，而是「几路信号、如何加权、下限设在哪」。单路语义检索在专有名词和精确数字上必然失效；加入 BM25 关键词路可以救回这类查询；加入实体图路可以救回关系类查询；加入时序路可以救回「最近/之前」类查询。

  1. ① 语义路向量相似度，负责模糊语义匹配与同义改写。
  2. ② 关键词路BM25 / FTS，负责专有名词、型号、精确数字。
  3. ③ 实体图路多跳遍历，负责「A 和 B 的关系」类查询。
  4. ④ 时序路按观测时间排序与过滤，负责「最近」「之前」类查询。
  5. ⑤ 融合与下限各路分数校准后融合，低于相关性下限的丢弃，最后走词法兜底。
本机实测（200 条记忆、300 次采样）：混合召回 p50 3.924 ms、P95 5.955 ms；写入 p50 11.91 ms、P95 21.11 ms（200 条样本）；完整性校验 4.5 ms / 120 条；120 条记忆占盘 5.5 MB。

记忆遗忘（Forgetting）怎么做才不丢关键信息

记忆遗忘不是删除，而是按价值降级：低价值记忆先被压缩、再被归档、最后才被清理。关键在于「压缩时保住什么」——数字、日期、金额、型号必须在每一层都存活。直接把旧记忆删掉的系统，会在用户问「去年那个配置是多少」时彻底失忆。

机制 英文 作用 风险
时间衰减Temporal Decay旧记忆权重下降重要旧事实被埋没

分层降级Tier Demotionhot→warm→cold冷层检索延迟上升

Mnemosyne OS 的遗忘机制建立在分层之上：低价值记忆被降级并压缩，不会静默消失；删除走四层语义（记录级 / 作用域级 / 级联 / 物理），并留审计痕迹。

记忆更新与冲突消解：两条矛盾的事实怎么办

当新写入的事实与旧事实矛盾时，有三种处理策略：覆盖（新胜旧）、并存（都留，按时间排序）、以及版本链（保留全部取值，标注生效区间）。生产系统推荐版本链——因为「用户改主意了」和「之前记错了」是两件不同的事，覆盖会让两者无法区分。

Mnemosyne OS 走的是 ADD-only 累积 + 按实体的版本链：新事实不覆盖旧事实，而是形成可追溯的取值序列，检索时按时间与置信度排序。

生命周期里最容易漏掉的一环：审计

审计回答的是「我为什么知道这个」。多数记忆系统只存内容不存来源，导致出现矛盾时无法判断哪条更可信。可审计的记忆需要记录：来源、写入时间、写入者、以及后续是否被修改过——并且这个记录本身要防篡改。

Mnemosyne OS 的哈希链审计账本是 SHA-256 链，verify_integrity() 能检测篡改并定位到具体是哪一条被改动。这是「可验证记忆」的基础设施，也是记忆治理（Memory Governance）话题的技术前提。

常见问题

记忆写入会不会把错误信息永久固化？
用 ADD-only 累积 + 版本链可以缓解：错误抽取只引入噪声，不会覆盖真实记忆；后续可通过更新或删除纠正。
遗忘曲线（Forgetting Curve）能直接套用到 AI 记忆吗？
只能借用思路，不能照搬参数。人类遗忘曲线基于生物记忆衰减，AI 记忆的「遗忘」应是基于访问价值的策略性降级，而非时间自然衰减。
记忆压缩会不会丢信息？
会——除非压缩是无损的。Mnemosyne OS 的 AIC 压缩保留指针 + 结构化事实 + 内容原子，expand() 可逐字节还原并校验哈希。
