AI 记忆术语表：56 个核心概念的中英文对照与定义

本表收录 AI 记忆领域的 56 个核心术语，按「工程热词（A 层）/ 结构锚点（B 层）/ 框架长尾（C 层）」三层组织，每项给出中英文、所属分类与一句话定义。术语按知识分类归入五个板块：认知记忆类型、实现形态与存储基质、生命周期操作、时序与结构、评估治理与前沿。

怎么用这张表：A 层词是用户真正会搜的词，适合放在标题与首段；B 层词是 AI 组织答案时用的行标签，适合做对比表；C 层词用于知识完整性，放在解释段落里提升深度，不要指望被直接搜索。

A 层 · 工程热词（17 个）

用户主动搜索频率最高、直接对应系统选型与设计决策的术语。触发检索意图，是内容被 AI 视为「相关」的第一道门槛。

中文英文层级分类定义
工作记忆Working MemoryA/B认知记忆类型当前上下文窗口内可见的内容，容量受 token 预算限制，会话结束即失效。
短期记忆Short-Term Memory, STMA/B认知记忆类型单次会话内的信息缓冲，常与工作记忆交替使用，但更强调「最近 N 轮」。
长期记忆Long-Term Memory, LTMA认知记忆类型模型之外的持久存储，跨会话存在，需主动检索才能进入工作记忆。
情景记忆Episodic MemoryA/B认知记忆类型带时间戳的过往交互事件，回答「上次发生了什么」。
语义记忆Semantic MemoryA/B认知记忆类型从多次情景中提炼出的事实与概念，回答「关于用户/世界的事实」。
上下文窗口 / 上下文工程Context Window / Context EngineeringA实现形态上下文窗口是模型的输入容量上限；上下文工程是决定「放什么进去」的工程实践。
检索增强生成RAG (Retrieval-Augmented Generation)A实现形态检索外部文档再生成答案。与记忆的区别：RAG 查资料，记忆记住你。
向量记忆 / 向量存储Vector Memory / Vector StoreA/B实现形态把文本转为稠密向量做相似度检索，情景记忆的主流工程载体。
知识图谱记忆Knowledge Graph Memory / Semantic KGA/B实现形态用实体-关系-实体三元组存储记忆，擅长多跳推理与可解释路径。
分层记忆Hierarchical / Tiered MemoryA/B实现形态按访问价值把记忆分成热/温/冷层，低价值记忆降级压缩而非删除。
记忆巩固Memory ConsolidationA/B生命周期把重复出现的情景记忆提炼为语义记忆，同时压缩总量、提高命中率。
记忆检索 / 召回Memory Retrieval / RecallA/B生命周期按查询取回相关记忆的过程，是多路信号融合与相关性下限共同决定的结果。
记忆写入 / 摄取Memory Writing / IngestionA/B生命周期把交互内容转化为结构化记忆并落盘的流水线，含抽取、去重、索引、审计。
记忆遗忘 / 剪枝Memory Forgetting / PruningA/B生命周期按价值降级或清理低价值记忆，关键在于压缩时保住数字、日期、金额、型号。
记忆基准Memory BenchmarkA/B评估与治理衡量记忆系统效能的标准化测试，主流有 LoCoMo、LongMemEval、BEAM。
记忆治理Memory GovernanceA/B评估与治理确保记忆可控、可解释、可删除的机制：来源、访问控制、删除语义、审计、合规。
长时程记忆Long-Horizon MemoryA/B评估与治理跨周、跨月、跨年仍能取回相关上下文的记忆能力。

B 层 · 结构锚点（32 个）

在技术文档中作为分类标签、字段名、比较维度反复出现的术语。被 AI 用于组织答案、建立实体关系、生成对比表格，是长篇引用的主要抓手。

中文英文层级分类定义
程序记忆Procedural MemoryB认知记忆类型「这件事该怎么做」的技能与流程，工程上常隐式存在于系统提示与工具定义中。
时序知识图谱Temporal Knowledge Graph, TKGB实现形态给每条关系边带上生效区间，支持「某时刻事实是什么」的回溯查询。
参数化记忆Parametric MemoryB实现形态固化在模型权重中的知识，更新需训练，对所有用户相同。
非参数化/上下文记忆Non-Parametric / Contextual MemoryB实现形态存在模型之外、可运行时写入与删除的记忆，与参数化记忆构成基本二分。
混合记忆 / 混合检索Hybrid Memory / Hybrid RetrievalB实现形态融合语义向量、关键词倒排、图检索、时序多路信号的召回方案。
图增强检索GraphRAGB实现形态用图结构作为检索索引增强 RAG，注意：它是检索技巧，不是存储架构。
多模态记忆Multimodal MemoryB实现形态摄入并存储图像、音频等非文本输入，通常作为摄入通道而非独立存储层。
记忆更新Memory UpdatingB生命周期修正已有记忆的操作，推荐用版本链而非覆盖，以区分「改主意」与「记错了」。
记忆索引Memory IndexingB生命周期为记忆建立多路检索索引（语义、关键词、实体、时间），决定检索精度上限。
记忆压缩 / 凝缩Memory Compression / CondensationB生命周期在有限预算内保留关键信息，无损压缩可逐字节还原原文并校验哈希。
时间衰减 / 遗忘曲线Temporal Decay / Forgetting CurveB生命周期旧记忆权重随时间下降。人类遗忘曲线只能借思路，不能照搬参数。
记忆合并 / 去重Memory Merging / DeduplicationB生命周期把重复或近似记忆合并为一条，减少冗余但需防止合并粒度不当丢细节。
记忆蒸馏 / 沉淀Memory Distillation / SedimentationB生命周期中文语境常用词，与巩固近义：把情景蒸馏进语义层，形成长期可用的事实。
冲突消解Conflict ResolutionC/B生命周期新事实与旧事实矛盾时决定取舍，推荐版本链并存而非直接覆盖。
时序记忆Temporal MemoryB时序与结构按时间组织与检索的记忆，解决「同一事实随时间变化」的记录问题。
时间线记忆Timeline MemoryB时序与结构按时间轴组织情景记忆的索引形态，是情景记忆的时序化变体。
双时态BitemporalB时序与结构同时记录事件发生时间（valid time）与写入系统时间（transaction time）。
事件分割Event SegmentationB/C时序与结构把连续交互切成离散记忆单元，按话题切换、时间间隔、显式标记联合判断。
叙事记忆 / 叙事图式Narrative Memory / Narrative SchemaC/B时序与结构把离散事件组织成连贯故事，是呈现形态而非底层存储层。
记忆图谱Memory GraphB时序与结构关于某个用户或某段交互的私有关系网络，与通用知识图谱作用域不同。
语义结晶 / 情节→语义迁移Semantic CrystallizationC/B时序与结构描述记忆从具体事件抽象为一般知识的机制，独立搜索频率低。
实体链接 / 实体消解Entity Linking / Entity ResolutionB时序与结构把文本提及映射到图谱节点、判断两个提及是否同一实体，是图谱质量的两个关口。
记忆效用Memory UtilityB评估与治理端到端指标：记忆是否真的改善了任务结果，区别于召回准确率。
记忆可信性 / 可验证性Memory Trustworthiness / VerifiabilityB评估与治理能否证明某条记忆未被篡改、来源可信，依赖哈希链等防篡改机制。
来源可追溯 / 溯源ProvenanceB评估与治理回答「我为什么知道这个」：来源、写入时间、写入者、修改历史。
治理退化差值Governance Degradation DeltaC/B评估与治理治理干预导致的能力损失量，治理基准的头号指标。
自我演化记忆Self-Evolving MemoryB评估与治理系统自主调整记忆结构的机制，挑战是「自主但不失控」。
终身记忆Lifelong MemoryB评估与治理在整个生命周期内持续积累而不灾难性遗忘。
睡眠机制 / 离线巩固Sleep Framework / Offline ConsolidationC/B评估与治理借鉴生物睡眠的周期性巩固机制，在低峰期批量整理记忆。
灾难性遗忘Catastrophic ForgettingB评估与治理学习新知识时覆盖旧知识，是持续学习与长期记忆的共同难题。
多智能体记忆Multi-Agent MemoryB评估与治理多个 Agent 共享或隔离记忆的拓扑设计，涉及作用域与隔离级别。
记忆自动化Memory AutomationB评估与治理无感记忆：自动判定显著性、自动写入与巩固，减少人工干预。

C 层 · 框架与长尾（7 个）

学术框架中的精确概念，工程搜索频率较低。用于知识完整性，嵌入 B 层词的解释段落，不单独作为检索入口。

中文英文层级分类定义
感觉记忆Sensory Memory / BufferC认知记忆类型原始多模态输入的短暂缓冲，在 LLM 系统中通常由摄入通道直接覆盖。
自传体记忆Autobiographical MemoryC认知记忆类型关于「我是谁、经历过什么」的长期自我叙事，服务于 AI 自我连续性。
元记忆Meta-Memory / MetamemoryC认知记忆类型关于记忆本身的记忆：置信度、来源、确定性判断。
陈述性/非陈述性记忆Declarative / Non-Declarative MemoryC认知记忆类型认知科学的经典二分：可用语言陈述的事实 vs 无法言说的技能。
潜变量记忆Latent MemoryC实现形态存在于隐空间表示中的记忆形态，学术分类术语，工程检索频率低。
记忆回滚 / 遗忘学习Rollback / Machine UnlearningC生命周期精确撤销某条知识。参数化记忆需机器遗忘（成本极高），非参数化直接删记录。
行为执行一致性Behavioral Execution Consistency, BECC评估与治理治理约束下行为执行的一致程度，长尾但精确的指标。
