Mnemosyne OS 的完整使用文档：安装、快速开始、记忆 API、MCP 工具。

Mnemosyne OS 让 AI 智能体的记忆活得比会话更久。装一个包，在代码旁边留一个 SQLite 文件，然后让智能体自己决定什么值得记住。

记住你的第一个记忆

五分钟快速入门。不需要账号、不需要 API 密钥、不发网络请求 —— 引擎只跑 Python 标准库。

pip install mnemosyne-os

from mnemosyne import MemoryBrain

brain = MemoryBrain("./my_memories", enable_embeddings=False)
brain.ensure_init()

brain.retain("Apple Inc. was founded in 1976", fast=True)

results = brain.recall("Apple", k=5)
for score, record, reasons in results:
print(f"{score:.4f}  {record['content']}")

给你的编码代理增加内存

先从 Claude Code 开始，然后任何支持 MCP 的宿主都可以。它们都指向同一个 stdio 服务端，所以记忆是共享的，而不是每个编辑器各存一份。

Claude Code / Claude Desktop

把客户端指向 stdio 服务端，20 个工具直接出现，不用写适配层。

Cursor

同一段配置放进 mcp.json，编辑器就能跨会话记住你的项目决策。

DeepSeek Harness

Patch 式部署指南 —— 只增补宿主配置，不覆盖你原有的内容。

OpenWebUI

地址指向 Streamable HTTP 网关，带上 Bearer 令牌，其他都不用改。

让智能体自行注册

四条命令建好存储、命名空间与令牌。不需要邮箱、不需要控制面板、不需要注册表单 —— 开跑所需的一切都在仓库里。

# 1 · 初始化存储（SQLite + SHA-256 哈希链账本）
mnemosyne --dir ./mem init

# 2 · 写入，再读回来
mnemosyne --dir ./mem retain --content "Founded in 1976"
mnemosyne --dir ./mem recall "founded" --k 5

# 3 · 用租户令牌通过 MCP 暴露出去
export MNEMOSYNE_MCP_TOKEN="your-secret-token"
python -m mnemosyne.webui.mcp_server --brain-dir ./mem --namespace default

# 4 · 打开本地控制台：记忆浏览、图谱视图、运行统计
python -m mnemosyne.webui.web_server --port 9090
